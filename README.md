# Advanced Data Analysis with Python

Welcome to the course repository for **Advanced Data Analysis with Python**, given at SciencesPo for the fall semester 2026/2027.

This repository contains the notebooks, exercises, datasets, examples,
and other materials used throughout the class.

## Course contents

The course is organized into the following modules.

| Session | Topic |
|---|---|
| **01** | Python Environments and Best Practices, AI-assisted coding tools |
| **02** | Advanced Control Flow and Data Structures |
| **03** | Advanced Functions and Functional Programming |
| **04** | Object-Oriented Programming and Modules |
| **05** | Recap |
| **06** | Web Scraping |
| **07** | Advanced Data Wrangling |
| **08** | Text Analysis and Natural Language Processing |
| **09** | Statistical Analysis and Machine Learning Basics |
| **10** | Geospatial Analysis and Advanced Visualization |
| **11** | Reproducible Research, GitHub and HuggingFace |
| **12** | Recap |
